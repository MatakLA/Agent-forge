# Getting help

| You want to... | Go to |
|---|---|
| install it and something fails | run `./forge doctor`, then [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) ("What can go wrong" in [docs/INSTALL.md](docs/INSTALL.md)) |
| know how something works or whether it fits your setup | [docs/FAQ.md](docs/FAQ.md), then [Discussions](https://github.com/MatakLA/Agent-forge/discussions) |
| choose an AI provider for your budget | `./forge pick-ai` and [docs/CHOOSING-AN-AI.md](docs/CHOOSING-AN-AI.md) |
| report a bug | [open an issue](https://github.com/MatakLA/Agent-forge/issues/new/choose) with the output of `./forge doctor` |
| suggest a feature | check [ROADMAP.md](ROADMAP.md), then open a feature request or start a discussion |
| report a security problem | **not** in public: use a [private advisory](https://github.com/MatakLA/Agent-forge/security/advisories/new) - see [SECURITY.md](SECURITY.md) |

Agent-Forge is maintained in spare time; there is no support contract and no guaranteed response time. A good report (what you
ran, what you expected, what happened, the `forge doctor` output - never keys or tokens) is the fastest way to a fix.
